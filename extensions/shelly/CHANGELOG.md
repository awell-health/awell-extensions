# Shelly changelog

## Unreleased

- `Step ID` (Summarize Form) and `Track ID` (Summarize Track Outcome) now accept a comma-separated list; steps or tracks that were not activated are skipped.
- Added optional `Step ID` input to Summarize Form to summarize forms from a specific step, e.g. in another track.
- Added optional `Track ID` input to Summarize Track Outcome to summarize a track other than the current one.
- Added tenant-level Shelly disclaimer text and placement settings with action-level overrides.
- Documented disclaimer precedence and defaults for Shelly summaries.
